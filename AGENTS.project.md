# Sunder — project instructions

The engineering instructions for this project live in **`CLAUDE.md`** at the
repository root. Read it fully before touching `src/game/`. It is a behavioural
contract, not documentation: it defines the completion gate (§S1), the searches
to run before building (§S2), how to choose between candidate mechanisms (§S3),
and when to stop patching and replace a representation (§S5).

`AGENTS.md` remains the sandbox contract. Where the two are both silent, the
user's global operating rules govern.
